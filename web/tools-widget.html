iPhone via Scriptable
Install Scriptable from the App Store — it's free. iOS gives no other way for a website to draw a home-screen widget.
Copy the script below, open Scriptable, tap +, and paste it in. Name it TAS.
Long-press your home screen → + → Scriptable → pick a size → Add Widget.
Long-press the new widget → Edit Widget → set Script to TAS. Tap the widget any time to jump straight into the calendar. 

        


        
        

          
Android via any webpage-widget app

          

            

              Install a webpage-widget app from Play — Web Widget or Webpage Widget both work.
              Chrome can't put a website on the home screen by itself; these apps draw a page inside a widget frame.
            

            

              Add its widget to your home screen and paste your widget link from above as the URL.
            

            

              Set the refresh interval to 15–30 minutes and turn scrolling off.
              Add &n=8 to the link for more rows on a tall widget, or &compact=1 to drop the header on a small one.
